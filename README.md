# Callsign finder

Find whether an ICAO aircraft type operates into an ICAO airport, and which callsigns those flights use.

Free live search uses ADS-B (adsb.lol) and only sees aircraft still in the air. Add a free OpenSky API client for yesterday’s completed arrivals, or a Flightradar24 Explorer token for up to 30 days.

```powershell
npm install
npm run dev
```
